# Personal Assistant Interaction Reference

The supplied reference presents the assistant as an always-available, visually distinct companion inside the product rather than a separate utility page. The key product cues applicable to Seif Study OS are: an immediate entry point, a conversational request field, awareness of the user’s work context, and an action-oriented promise to make changes on the user’s behalf.

For this study platform, the assistant will be implemented as a persistent floating entry point and a focused chat panel. It will respond in Egyptian Arabic, recognize common study-management requests, present a compact preview of any proposed action, and require explicit confirmation before deletion or material edits.
